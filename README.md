## Run Locally

No build step or package installation is required.

```bash
git clone https://github.com/nworieugochukwu123-max/paul-portfolio.git
cd paul-portfolio
python3 -m http.server 8000
```

Open http://localhost:8000 in a browser.

## Project Structure

```text
.
├── index.html       # Page markup, styles, and scripts
├── README.md        # Project documentation
├── robots.txt       # Search crawler instructions
├── sitemap.xml      # Page index for search engines
└── images/          # Profile and project assets
```

## Customization

Update portfolio content and metadata in `index.html`.

- Replace personal, project, and contact details.
- Add or replace images inside `images/`.
- Keep image alternative text descriptive.
- Update the canonical URL and social metadata if the final domain changes.
- Update `robots.txt` and `sitemap.xml` to match the final domain.

## Contact Form

The form uses EmailJS. Before reusing the template elsewhere, create an EmailJS account and replace these values in `index.html`:

- Public key
- Service ID
- Email template ID

## Deployment

The site can be deployed on GitHub Pages or any static web host. For GitHub Pages:

1. Push the repository to GitHub.
2. Open **Settings → Pages**.
3. Select the `main` branch and `/ (root)` folder.
4. Save and wait for the deployment to finish.
